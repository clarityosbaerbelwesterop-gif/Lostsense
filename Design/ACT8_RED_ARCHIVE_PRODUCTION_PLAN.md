# LOSTSENSE — Act VIII Red Archive Production Plan

The authored route is Choirless breach → Ashwake Wastes → Ember Court → Vask quota yard → Foundry Cathedral (20034) → Prelate Ilyr Vael (30055) → the door toward the Last Archive.

The Ember Compact is treated as a political/social faction rather than generic enemies. Quests 80070–80073 are explicit traversal, negotiation and mechanism beats. Ilyr's defeat commits 80074; the post-boss door is a separate 80075 beat and therefore cannot open before the fight.

Ilyr has three source-level phases matching The Necessary Man, Second Silence and Mercy Engine. The arena keeps external conduit geometry readable and does not transform him into a generic demon.

This source pass does not claim UE 5.8 UHT/UBT/PIE, animation, VFX, audio, navigation, packaged-build or Pixel Streaming runtime validation.
